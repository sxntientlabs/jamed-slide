# Third-party notices

## AICSS React

Koasis uses the public MIT-licensed primitives from `@aicss/react` by AICSS for thinking state, orbs, text response, code blocks, and data tables. The public `streaming-text`, `thinking-reasoning`, `reasoning-effort`, `message-actions`, and `secure-input` sources are copied/adapted under `src/components/aicss-public/` so their visual and interaction behavior can be used directly in the app. The remaining domain surfaces—citations, comparison tables, file diff, audio waves, image processing, to-do lists, agent input, and approval gates—are Koasis-native equivalents because they need clinical privacy and workflow behavior.

Source: https://github.com/kvnkld/aicss

The copyright notice and permission notice from the package are retained in the installed dependency under `node_modules/@aicss/react/LICENSE`.
